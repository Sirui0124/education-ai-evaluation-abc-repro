# 模块 C 学生评价评分规范 v1.1.1

最终标量采用“已表达／已支持的积极理解”保守证据分。每个维度取已记录证据的加权下界；原文未明确表达时贡献为 0，但语义值仍为 null。这不是潜在满意度或真实收益估计。第 8 项及 8 指标映射仍待主任务确认，“字数收益”暂按自述收益设计。任何情况下不奖励字数或发帖量。

## 原子与锚点

| 维度 | 原子及默认权重 |
|---|---|
| S 满意度与积极态度 | S1 整体体验 50%；S2 认可学习支持价值 25%；S3 继续使用/推荐意愿 25% |
| B 自述收益 | B1 理解思考、B2 实践迁移、B3 效率推进、B4 自主调节，各 25% |
| E 证据支持 | E1 自述具体性 20%；E2 主张定位 20%；E3 原始行为支持 60% |

S：明确否定或中性且无正向认可为 0；微弱或严格有条件认可为 0.25；同一方面实质正负权衡为 0.5；明确肯定包括简单“好用、有帮助”为 0.75；明确强烈肯定为 1。未表达该方面保持 null。S3 按明确使用/推荐意愿解释。

B：明确无收益或退步为 0；笼统声称帮助为 0.25；具体任务有所改善为 0.5；自己的具体改变或行动为 0.75；明确前后状态或已完成结果为 1。1 也只是自述。退步另记 negative_change。

E1：泛泛表述 0、收益领域 0.25、明确任务 0.5、自己的具体行动 0.75、可核查过程/前后状态/结果 1。E2：仅身份关联或已查无对应 0、主题近似 0.25、任务对应但会话不清 0.5、会话对应但时间等细节不足 0.75、学生/学期/事件/轮次准确对应且时间相容或有明确交叉引用 1。E3：已查无支持或有反证 0、仅相关尝试 0.25、部分支持 0.5、核心主张有直接支持但范围有限 0.75、完整覆盖该具体主张所需原始学生行为 1。反证和查无支持保留不同核验状态。

声称“改善”需要可比前后学生行为；声称“能做”需要对应实际表现。AI 回答、AI 赞扬、已有评分不是行为佐证。E1 衡量具体性，E2 衡量定位，均不能替代 E3。E3 不证明作者独立性或 AI 因果增益。

批评准确性或要求更深讲解，不自动降低理解收益；明确不满整体体验则如实影响 S1。正面态度不能转成已经产生的收益。文风像 AI 不构成排除依据。

## 可执行的评分流程

每位评分代理读取分配学生的全部反馈原文及冻结会话。保留每条反馈的纳入/去重决定，但不逐句拆解所有细碎主张。针对每个原子提取最小充分语义主张及支持原句，保留会改变判断的关键反证。可以复用引用，不能用关键词计数替代全文语义判断。

非空 duplicate_group_id 仅作候选并核对；同一学生规范化文本完全相同时合并，原句仍保留原始形式。同一目标/方面/事件的重复表达不增加权重。题目、模板及引用 AI 的自评不作为本人收益；有本人实质陈述的回复可纳入。

每原子在全部纳入记录中确定有效语义锚点的最低和最高值，取 `(min+max)/2`，缓存决定两个端点的最小充分引用即可。单一锚点取原值，无明确表达留空。同分或重复帖不影响结果，不挑最高分记录。跨度达到 0.5 或有事实矛盾时标记复核。明确撤回可替换旧主张并记录 supersedes；较晚日期本身不覆盖旧记录。

核验窗口扩为该学生全部冻结 sessions。材料路径、哈希及字段映射由主任务材料清单绑定到 rubric.sources.all_frozen_sessions。现有 valid_dialogues 仅作补充入口，不能以只查有效对话声称已完成全窗口核验。确有待查证主张且材料未到位时保持 NOT_VERIFIED，不输出完成分。

## 最简原子缓存

一行一个学生：student_key、rubric_version、source_manifest、annotator、record_decisions、student_atoms（固定 10 项）、review_flags。source_manifest 保存文件路径、SHA-256、读取范围；annotator 保存评分者、模型或人工、提示版本、时间。

每条 record_decision 只需 record_id、included、canonical_record_id、reason。每个 student_atom 保存 atom_id、value、status、claim、support_refs、counter_refs、reason、verification、negative_change、conflict_flag。claim 可以用一句语义判断附最低/最高锚点，无须穷尽主张列表。

引用最少包含 source_file、source_record_id、text_field、quote、start_char、end_char、speaker_role；对话补 dialogue_id、turn_index。无原生唯一 ID 时补 jsonl_line_1based。反馈 ID 用原始 record_id，对话用完整原生会话 ID。字符范围以 JSON 解码后的 Unicode 码点为准，0 起点、左闭右开，必须满足 text[start_char:end_char] == quote。

verification 只需 status、checked_scope_ref、support_refs、counter_refs、reason。checked_scope_ref 指向材料清单及检查过的学生会话 ID 清单；reason 简要说明身份、学期、任务、时间是否匹配及限制。身份匹配不等于事件匹配，更不等于行为支持。

## 状态、最终标量及调权

| 原子状态 | 缓存 value | 证据分贡献 | 完成要求 |
|---|---|---|---|
| OBSERVED | [0,1] | 原值 | 有精确证据 |
| NO_EXPLICIT_STATEMENT | null | 0 | 已读原文但未明确表达；不能均值填补 |
| OUT_OF_WINDOW | null | 0 | 实际检查后确认超出冻结窗口，并说明范围 |
| AMBIGUOUS | null | 0 | 保留语义歧义和复核标记 |
| MISSING_SOURCE | null | 0 | 无来源；仅此状态可能按后续用户授权另建填补分 |
| NOT_VERIFIED | null | 暂不定最终分 | 必须实际核验，阻止完成 |

有原文但无正向证据不属于 MISSING_SOURCE。只有态度、无收益/行为主张时 E1=0，E2/E3=null、NO_EXPLICIT_STATEMENT，不强求不存在的收益主张核验；有待核验主张就必须检查。未查不能改标 OUT_OF_WINDOW。

每维权重非负且合计大于 0，归一化为 w。观察掩码 m 仅在 OBSERVED 时为 1。下界 L=Σ(w×m×value)，覆盖率 C=Σ(w×m)，上界 U=L+1−C。所有必要核验已完成时，最终 score=L；任一 NOT_VERIFIED 或所需材料未绑定/未检索完成时，score=null、completion_status=INCOMPLETE，可展示 provisional_lower 但不得用于完成排名。

其他空值允许 COMPLETE_WITH_LIMITS，显示相应限制。C 衡量明确原子数值的覆盖率，不等于原文可用率；原文可用情况由 source_manifest 和 record_decisions 单列。U 是把所有空值置 1 的宽松敏感性上界，涵盖未表达的潜在内容，不代表已有支持。全无来源者下界 0、上界 1，不能解读为真实零收益。

Excel 用辅助 NumericValues 把空值转 0，原始 value 保持空白。Lower=SUMPRODUCT(NormalizedWeights,ObservedMask,NumericValues)；Coverage=SUMPRODUCT(NormalizedWeights,ObservedMask)；Upper=Lower+1−Coverage；Score=IF(IncompleteCount>0,"",Lower)。不按已观察项重新归一化，不使用缺失均值回填。MISSING_SOURCE 的均值填补当前关闭；若主任务获得授权，另建 imputed_score，保留原分、供体群体、填补公式和值。

仅改权重不重跑 LLM。源数据、核验窗口或语义锚点变化才重评受影响原子。第 8 项映射保持未启用；主任务确认后可用相同确定性公式组合 S、B、E 及其覆盖率和上下界。

本次仅交付规范；没有对 165 人执行评分，没有调用收费模型，没有修改母源。v1.1.1 取代 v1.0.0 的“必须全部原子有值才能完成”及“中性满意度记 0.5”口径。
