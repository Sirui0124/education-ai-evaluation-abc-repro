# AIV指标定义、性质与使用边界

## 理论内容

本轮采用非负权重的加权和。主评分只使用已有全样本可计算依据的四项：整体CTQ进展、平均CTQ进展、最高知识点CTQ进展、QAPro占QA3的比例。自然CTQ用于调整前三项，不另作加分项。DHI、MAB、学生场景与评价保留为条件指标，其中MAB另做弱权重对照。未完成统一编码的错误纠正率、自主推理率保持缺失。

表1 评分步骤

| 步骤 | 操作 |
|---|---|
| 1 | 固定数据快照、学生与学期标识、概念分类及有效before/after证据。 |
| 2 | 对全部有效对话构造观察进展；对完整概念配对另判断基线调整资格。 |
| 3 | 计算概念进展、学生总进展/平均进展/峰值进展，以及QA质量比例。 |
| 4 | 用固定理论界归一化，分别应用规范权重与分组熵权。 |
| 5 | 使用同分平均秩，保留前后20%边界的所有同分者，检查方案与假设敏感性。 |

这一流程保留全量学生，不把未满足基线条件者从观察榜中删除，也不以零填补其缺失的基线调整结果。

### CTQ与学生层汇总

设概念内配对的before、after评分为$b,a\in[1,6]$，定义单对进展$g=\max(0,a-b)/5$。观察榜在同一学生同一概念的有效、同任务对话中取最大$g$作为$g_{ic}$；调整榜使用上游已通过资格检验的概念最早before与最高after配对，不能用后来有效窗口替换缺失的原始概念before。

数值相减采用量尺内等距的工作假设。三级经验代理与直接六级的数值区间一致，不代表它们已被验证为相同测量量尺；类别标注的一致性也不自动证明数字间距具有等距含义。

概念CTQ有界于$[0,1]$。上升产生非负进展，下降为零，满足附录C允许的零负向贡献口径；无变化基准为0。它不把轮数、字数或重复对话作为乘数，复制同一有效配对不会改变最大值。保留原始$a-b$用于检查下降，但主CTQ不将下降记成负数。

**划分一致性有条件成立。**只改变呈现分段、不改变固定配对端点与概念归属时，CTQ不变。若改变有效对话窗口定义，则观察榜的最大窗口进展不保证不变。例如L1→L3→L5整体配对为0.8，拆成两个独立配对后最大值为0.4。因此本轮固定上游对话边界、记录全部候选配对与被选配对。这是对附录C一致性条款的明确偏离说明，不能写成无条件成立。轮次不直接加分也不等于统计上完全不受采样次数影响：更多窗口可能更容易观察到峰值。

学生层以概念为单位汇总，不按消息重复累加。观察榜使用概念等权$u_c=1$；基线调整榜使用课程目标代理权重：L3为0.6、L4为0.8、L5/L6为1。这些目标与重要性仍属建模建议，不是教师已确认权重。

$$S_i=\sum_{c\in C_i}u_cg_{ic},\qquad M_i=\frac{\sum_{c\in C_i}u_cg_{ic}}{\sum_{c\in C_i}u_c},\qquad P_i=\max_{c\in C_i}g_{ic}.$$

三者分别描述跨概念总进展、每概念平均进展和最佳突破。它们不是互相独立的能力维度；仅有一个可评概念时平均值与峰值完全一致。不同方案只分配认知指标族内部的侧重，不把三项重复测量解释成三份独立证据。总进展允许“在更多概念上获得真实进展”提高分数，但对话数量本身不加分。

### 自然基线与调整值

采用固定的概念×课程模块×量尺组$G_c$，目标为$T_c$。以$q=0.23$作为主情景，$q=0.48$作为对照：

$$n_c(q)=\frac{q}{|G_c|}\sum_{j\in G_c}\frac{\max(T_c-b_{jc},0)}5,\qquad r_{ic}(q)=g_{ic}-n_c(q).$$

调整后的总和、均值、峰值依次以$r_{ic}$替换上一式中的$g_{ic}$。净峰值必须是$\max_c r_{ic}$，不能把最高实际进展减去某个不对应的整体基线。自然基线只扣一次。所有负调整值保留；目标缺失、配对不可比、同一学生含不同量尺时，不强造调整值。

基线按本批合格概念组的before计算并随快照固定，组内成员与人数在元数据保留。它不充分控制个人常规学习能力、勤奋、不同时间窗口及选择偏差。23%与48%是外部研究迁移的情景参数，不是本班实测无AI增长率，也不是置信区间上下限。更换校准群体、目标或量尺后须另建版本。此处“调整”只能作给定假设下的比较，不能宣称因果AI净增量。

### QA质量与条件指标

质量项$Q_i=QAPro_i/QA3_i^{含Pro}$，统计采用已纳入课程对话口径，不含无效QA。分母为零时缺失，分子为零且分母正时为真实零。小分母的高比例不等于稳定质量，故同时展示分子、分母，不把比例解读为测量精度。质量项不扣自然认知基线，因此调整综合分也不等于纯认知净增量。

MAB统计日志可见范围内去重的不同智能体名称，记为$m_i$。敏感性中使用$B_i=1-\exp[-\max(m_i-1,0)]$。对$m_i\ge1$，其一阶导数为正、二阶导数为负，因而单调、饱和、边际递减；单智能体基准为0。不可见的智能体信息为缺失，不填成0或1。缺失者不做逐人权重重分配，MAB只在相同完整子样本上与零MAB方案比较。

学生讨论沿用最新“使用场景”和“评价倾向/评价方面”两条分类轴。它们用于学生反馈与场景诊断，不自动转成自主能力分，不沿用已废弃的旧自主等级。主评分权重为0，不能把正面自述当成独立学习收益证明。

### DHI的对称与非对称构造

令$p$为同量尺下的层次端点分布，$F_k(p)$为前$k$层累计比例。研究者设定六级理想分布$q^*=(.05,.15,.25,.30,.15,.10)$，三级理想分布为$(.20,.55,.25)$；这是强调中高阶且保留低阶基础的教学目标情景，尚无教师确认或独立实证。对称距离$d_s(p,q^*)=\sum_{k=1}^{K-1}|F_k(p)-F_k(q^*)|/(K-1)$，定义$DHI_s=1-d_s$。

非对称距离使用低阶过多的双倍代价：$d_a=\sum_k[2\max(F_k(p)-F_k(q^*),0)+\max(F_k(q^*)-F_k(p),0)]/(K-1)$。令$D_{max}=\max_{h=1,...,K}d_a(e_h,q^*)$，取$DHI_a=1-d_a/D_{max}$。距离为凸函数，单纯形任意点是顶点凸组合，所以其值不超过顶点最大值，保证归一后有界。

两个DHI都在理想分布处唯一取1，随各自定义的距离增大严格下降。对称型对同幅累计偏差等罚；非对称型对低阶过多与高阶过多区别处理。两者均不能同时保证“认知层次越高必然越健康”，因为超过内部理想目标也可能增加距离。这与用户偏好的纯增量奖励不完全一致，也是本轮不纳入主加分的原因之一。

本批DHI以有效配对的before/最高after端点构造，不是所有学习活动的真实层次分布。少量对话与最高端点选择会影响估计，DHI保持诊断用途，不以数值可算替代可靠性论证。

### 推荐聚合与数学性质

固定归一界：观察榜$z_S=S/12,z_M=M,z_P=P$；调整榜$z_S=(S+12)/24,z_M=(M+1)/2,z_P=(P+1)/2$；两榜$z_Q=Q$。12是固定概念数上界，不取本批最大值。若未来概念体系改变，必须同步修订版本，不能沿用旧上界。异常越界应先检查源数据，不把截断当作纠错。

推荐可解释的均衡型作为默认展示：

$$AIV_i=100\left(0.30z_{S,i}+0.25z_{M,i}+0.15z_{P,i}+0.30Q_i\right).$$

全部权重非负、和为1且输入在$[0,1]$，因此AIV在$[0,100]$，每个评分子指标提高都不会使AIV降低。此结论要求权重、基线与归一参数固定；熵权若随数据重新拟合，不能再声称跨批次的全局单调性。自然基线本身是控制量，提高它会降低调整进展，不属于“越高越好”的评分子指标。

每项贡献均为$100w_jz_{ij}$，可逐项相加解释得分。固定界避免单个异常极值重塑全班尺度，且单个归一指标变化导致的分数变化最多为$100w_j$。对权重扰动，$|AIV'_i-AIV_i|\le50\|w'-w\|_1$；这一分数上界不保证近分学生的名次不变，排名稳健性仍须实测。

最大值CTQ仍对错误的峰值标签敏感。有界只能限制分数影响，不能证明对标注异常不敏感。案例复核已发现需复核的起点和L6证据，本轮保留原标签并标注风险；若要将附录C的异常值稳健性落实到高风险个体决策，还需独立复标及标签扰动验证。因此这里不宣称所有公理均已在实证层面无条件满足。

调整榜零净进展对应认知归一值0.5，故综合分不以0为“无AI收益”分界。Excel和JSONL同时保留未平移的负/零/正净进展，避免仅看综合分误读。不同量尺各自使用固定变换并不证明测量等值；全量排名是探索性总览，量尺内排名更适合直接比较。

## 结果内容与读取方式

本次冻结范围为174名学生、195条有效对话，2025秋137人、2026春37人。146人满足固定假设基线调整条件。逐学生各指标、各方案得分与名次，以及稳健性数值以同目录最终Excel、学生排名JSONL和权重计算报告为准。

表2说明，本轮排名能够描述现有证据，却不能替代稳定的个人学习能力测量。尤其不能把平均/峰值高度一致误写成多指标互相验证，也不能因为一条QAPro就断言其使用质量长期领先。讨论匹配仅为学生身份关联，不等于讨论内容已逐条验证同一对话产生的学习效果。

174人是按冻结上游“COMPARABLE、同任务、起止评分均存在”的规则纳入，不代表174人都完成了独立的前测与后测。上述同锚点记录保留在用户指定的全量中并单列标识，零变化只能解释为没有观测到额外上升，不能判断学习失败。

推荐均衡型主要因为其固定、透明、可复算，且将认知族预算约束为70%、质量为30%。该推荐不是通过独立学习效标验证出的最优权重。突破优先型用于观察最佳概念突破，质量导向型用于教学对话质量诊断，分组熵权用于检验数据离散度驱动的替代排序。三类应用目的不能解释成学生、技术员与教师努力的因果贡献分解。

MAB检验分别在137人观察完整样本和115人调整完整样本开展。5%方案权重为总进展28%、均值24%、峰值13%、质量30%、MAB5%；零MAB参照把前四项除以0.95，保持四核心比例不变。加入5%MAB后前20%Jaccard分别为0.647和0.516，最大名次变化分别23.5和20。这说明“弱权重”仍可明显改变前列，故不推荐纳入主分。该检验与独立复算一致，未将不同名单或不同核心比例造成的变化误归于MAB。

均衡观察榜前、后20%各35人，前组平均CTQ为0.452、QA质量均值0.971，后组分别为0.040和0.476。调整榜目标名额为30人，前组边界有同分，实际纳入31人，后组30人；前组QA质量全部为1。这说明前后组数值差异符合合成规则，但质量项对调整榜有明显影响。总进展名义权重为30%，本批实际贡献范围仅观察榜2.50分、调整榜1.30分；质量项贡献范围为22.50分。应同时查看贡献与原始净进展，不能把名义权重当作样本中的实际影响强度。

六例原文复核另见`diagnostics/案例复核.md`。其中观察均衡榜第1名259329为64.00分，第2名259869为57.50分；后者CTQ更高但QA质量比例较低。两名CTQ为0且QA质量为1的学生仍各为30.00分，全部来自质量项。高CTQ案例中的低起点证据、L6构造充分性和三级分档压缩均存在需复核的具体问题，因此不能用“与直觉一致”替代测量效度检验。

总体推荐是：均衡线性加权作为可调整的展示默认值，四方案并列，原始进展与负调整值必须伴随呈现。学生反馈、Agent比较和教学切入点优先依据分项与具体证据讨论。跨班推广需重新检验量尺等值、概念覆盖、QA标注口径及基线假设；本结果不宜直接用作高风险的学生奖惩或宣称AI因果净收益。
