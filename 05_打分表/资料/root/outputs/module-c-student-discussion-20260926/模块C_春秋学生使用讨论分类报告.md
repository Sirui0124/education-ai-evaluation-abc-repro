# 模块 C 春秋两季学生使用讨论分类报告

## 结论

当前不建议把“学生自主使用与反思”直接设为 AIV 的正式加分项。它可以继续留在 14 项重点比较中，状态为“待定纳入、权重可为 0”。现有材料适合描述学生如何陈述使用目的、策略、核验和迁移，但不足以证明这些行为真实发生，更不能证明 AI 带来了认知增量。

最主要的限制来自材料形成机制。2025 秋季的话题讨论明确计入总评，2026 春季文件中的“自由讨论”只是平台参与模式，两者都不能证明学生自愿使用。多数文本又直接回应教师给定的提示，因此写出知识点、收获或学习计划不构成自主性的充分证据。

本次在 478 个“学生×学期”中，仅 5 个出现了较明确的延伸动作描述，例如进一步查询、补充专业文献或继续追问；这些仍然只是讨论文本中的行为自述，没有一条与具体日志、作品或可复核产出形成可靠的一一对应。当前已核验自主行为数为 0。

## 分类口径

七个维度允许多标签：使用目的与情境、选择与理由、主动尝试与策略调整、核验纠错、反思与迁移、自述收益、依赖与困难。

L0–L3 只表示讨论文本中证据的具体程度，不是学生能力分数：

- L0：未观察。它代表材料中没有证据，不能解释为能力为零。
- L1：泛泛自述或简单提及。
- L2：具体情境、理由、步骤、局限或收益的自述。
- L3：第一人称具体行为自述。没有独立日志或作品时，仍不升级为已核验行为。

自主证据另列三类：A0 为未观察到自主动作，A1 为任务内选择或主动动作自述，A2 为具体延伸行为自述且未日志核验。多智能体出现、发帖数、篇幅、正面态度和完成提示要求均不直接加分。

讨论文本自身如果展示了比较、推理或纠错，可以标记为“讨论内呈现具体推理”。这只说明帖子中出现了相应内容，不证明工具使用过程已经发生，也不证明学生独立完成。

## 分类结果

在学生×学期层面：

- A0 未观察到自主动作：331 人。
- A1 任务内选择或主动动作自述：142 人。
- A2 具体延伸行为自述、未日志核验：5 人。
- 可关联具体日志或作品的已核验自主行为：0 人。

七个维度出现任一级别证据的学生数分别为：使用目的与情境 476 人、选择与理由 457 人、主动尝试与策略调整 460 人、核验纠错 168 人、反思与迁移 383 人、自述收益 469 人、依赖与困难 194 人。

使用目的、自述收益和任务过程接近全覆盖，主要原因是教师提示本身要求学生写知识点、交流过程和收获。这些维度存在明显的提示诱导和天花板效应，不适合直接区分学生。核验纠错和依赖困难相对稀少，但仍需区分“学生检验 AI 输出”“智能体纠正学生回答”“学生讨论算法本身的局限”三种不同情形。

内容质量复核发现 164 个精确重复组，共涉及 570 条记录，其中主帖 244 条、回复 326 条；另有 42 条带有欢迎语、角色口吻、Markdown 标记等特征，疑似直接粘贴智能体输出。重复或疑似粘贴只作证据质量标记，不自动判定学术不端，也不进入加分。

## 与 QAPro 和 QA3 的对齐

按“学期＋原始学号”精确匹配，478 个学生×学期中有 351 个可与 `学生指标采纳版.jsonl` 对齐，127 个未匹配。分学期看，2025 秋匹配 254 人、未匹配 93 人；2026 春匹配 97 人、未匹配 34 人。没有使用姓名相似、跨学期同号或模糊匹配。

精确匹配只证明同一学生在 QA 数据中存在。秋季讨论缺少可用于一一连接会话的可靠时间与记录标识，春季讨论日期也不足以唯一定位 QA 会话，因此没有把讨论行为标为日志已核验。

在 351 个可匹配学生中，A0、A1、A2 三组分别有 246、102、3 人。A2 样本太少，且仍是自述，无法进行稳定的组间比较。A0 与 A1 的 QAPro、QA3 记录量差异还会受到会话数量、提示结构和课程参与程度影响，不能据此宣称自主评价具有增量效度。

## 是否纳入 AIV

建议继续保留为待定候选，不进入当前正式加分：

1. 它与 QAPro、QA3 的区分点应限定为使用策略、独立核验和跨情境迁移。知识理解、推理深度和具体建模内容已经由 QAPro、QA3 覆盖，再次计分会重复计算。
2. 泛泛收益和任务内合规回应不进入正向计分。即使文本很长，也不提高证据等级。
3. 如果后续要转为正式指标，建议只保留三层证据状态：具体自述、讨论内呈现、独立证据核验。只有能够关联日志、作品或版本记录的自主延伸与核验纠错，才可进入正向计分候选。
4. 在确定权重前，需要对一部分学生做人工双评，报告一致性；还要建立讨论记录与会话日志或作品的可靠连接。当前只有单模型编码，不能宣称已完成独立评审一致性检验。

## 交付文件

- `逐条讨论编码.jsonl`：完整逐条编码，含文档、段落、学生标识、日期、原文、证据状态、重复标记和 QA 对齐状态。
- `逐条讨论编码.csv`：便于其他工具读取的扁平明细。
- `学生学期汇总.jsonl`：按学生×学期汇总七维证据、自主证据和 QA 对齐结果。
- `复核清单.jsonl`：集中列出精确重复、疑似智能体输出、具体延伸行为自述和讨论内核验描述。
- `春秋学生使用讨论分类.xlsx`：面向复核的学生级 Excel，包含结论口径、学生汇总、逐条编码、材料覆盖和复核清单。
