# 模块 A–C 五板块交付索引

本仓库按工作流拆分现有模块 A–C，版本冻结于 2026-09-27。项目使用源方提供的脱敏教学对话与评分材料。公开副本进一步遮蔽了残留邮箱和 11 位号码，保留完整会话行、评分和统计字段；遮蔽清单见 `PUBLIC_REDACTIONS.md`。`资料/root/` 对应计算项目，`资料/notes/` 对应写作资料；`文件校验清单.json` 记录原始来源哈希，`PUBLIC_SHA256.json` 记录公开副本哈希。原工程文件未移动或修改。

## 30 分钟内复算

从 GitHub 下载仓库 ZIP 或 `git clone` 后，在仓库根目录运行：

```bash
python3 reproduce.py --claim all
```

运行不调用模型、不联网、不需要 API Key 或第三方库；已在 Python 3.9 验证，通常数秒完成。随机抽取一个已登记数值结论：

```bash
python3 reproduce.py --claim random --seed 42
```

`--claim` 还接受 `A-FUNNEL`、`B-AGREEMENT`、`B-STUDENT`、`C-AIV-OLD`、`C-WEIGHTS`。每项如何从输入逐步计算，见 [结论与复算范围](CLAIMS.md)；数据字段见 [数据字典](DATA_DICTIONARY.md)，运行条件见 [环境说明](ENVIRONMENT.md)，正式版本和论文数字的核对见 [版本一致性审计](VERSION_AUDIT.md)。数值脚本验证冻结标签的下游计算。语义标注本身需按原文、量尺与证据人工复核；重新调用大模型不会保证生成相同标签。

| 板块 | 入口 | 交付边界 |
|---|---|---|
| 01 数据清洗与标记 | `code/qa_labeler_v1/README.md`、QA3 v3.1、QAPro v2.4、领域标签 | QA3 需语义标注；QAPro 可按固定命中规则复算；领域仍需人工校准 |

| 04 学生评分产出 | `逐对话采纳及学生指标.xlsx`、学生领域与学生指标 JSONL | Before/After 只在同领域、同量尺、证据可核对时比较；缺失保留缺失 |

## 读取顺序

先读每块根目录的 `说明.md`，再读相关规则和数据。输入一批新学生对话时，依次执行 01 的清洗/标记、02 的认知评分、03 的一致性与人工复核、04 的学生维度汇总，最后按 05 的指标方案生成打分表。这里交付的是现有冻结成果与复算材料，跨目录旧脚本中有本机绝对路径；移植到另一台机器前须配置路径，不能直接宣称一键贯通运行。

## 文件校验

`文件校验清单.json` 记录本地源项目的逐文件哈希，`PUBLIC_SHA256.json` 记录公开副本哈希。第三块的复核队列由以下命令生成，默认对双标一致条目抽取稳定的 10%：

```bash
python3 03_模型测算与人工抽检/build_review_queue.py \
  --input 03_模型测算与人工抽检/资料/root/workspace/data_clean/module_b_cognitive_qapro_v5/record_labels.csv \
  --output 03_模型测算与人工抽检/人工复核队列.csv
```

该队列按“U 与可评分分歧／缺标、普通双标分歧、双标一致校验样本”排序。人工复核需要回到完整学生原文与证据行；仅凭 CSV 标签无法重新判定认知层次。
