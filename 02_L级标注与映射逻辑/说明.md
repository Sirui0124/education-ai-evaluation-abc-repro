# 02 L级标注与映射逻辑

正式 v5 对最早 QA3 任务的首个有效学生回合评分为 Before；对全场既有 QA3 任务中学生实际展示的最高层评分为 After。六级和独立三级分别评分，U 保留为证据不足。仅 QA3 的六级封顶 L2，最高分只对 QAPro 会话输出。`rubric_s6.md`、`rubric_s3.md`、`protocol.md` 和两个 v4 Prompt 是执行入口。

领域内数值折算使用冻结的五折留出映射，配对与教学目标见 `模块映射配置.json` 和 `折算规则.md`。折算分是经验代理值，并非整数 L 级，也不证明不同学科领域量尺等值。Agent 与 L 级的资料说明的是设计依据，不能拿 Agent 名称代替学生实际证据评分。
