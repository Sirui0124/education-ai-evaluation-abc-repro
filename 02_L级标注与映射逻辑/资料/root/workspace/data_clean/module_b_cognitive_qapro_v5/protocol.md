# 本次执行规则（优先于历史 Prompt 中的输入说明）
每场完整会话一行；最新版 QA3 v3.1 + QAPro v2.4，708场，其中425场QAPro，283场仅QA3。分类固定，不重判准入。
使用所给v4量尺。L级与独立三级分开、新上下文执行，不互相映射。两模型独立双标，不读另一模型结果或历史标签。语义逐条阅读，禁止关键词、长度、正则或模板算法代替评分；代码仅用于IO和校验。
基线：最早QA3任务的第一个effective_student_turn；输入仅保留该任务开始至该学生回合（包含紧邻AI上文），无未来信息。只评分target_student_turn学生表达；此前用于语境和复述检查。
最高：读取整场完整对话，仅在标记的QA3任务范围内评分学生表现，取全场这些任务中已实际展示的最高层；不把无关话题/AI答案归给学生。不预设必然有跃迁。
仅QA3的六级最多L2：若原始表现超过L2，保存raw_label原判与reason，label按本次用户研究约束封顶L2；U保留U。不因未进入QAPro默认L1。三级仍独立判，不从L级推算。
每条输出id,label,raw_label(通常同label),evidence_turn_ids,evidence_quote,support,confidence,reason,u_reason。引文必须逐字存在学生原文；U空引文。最高只对425场QAPro输出；仅QA3最高两项为空。
评分Prompt中的“不要读其他文件”指禁止额外资料/历史结果，允许读取本任务指定规则、输入，以及自己输出做机械完整性检查。
